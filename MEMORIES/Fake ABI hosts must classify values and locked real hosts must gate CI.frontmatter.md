A WAST host that merely counts calls can accept the right scalar signature with
values in the wrong positions. Vibesteroids' laser voices passed that fake even
though `700` and `350` occupied Aedicule's filter-enum slot and one waveform was
zero; the real renderer rejected configuration with `unsupported synth filter`.

Give deterministic WAST doubles cheap domain checks for enums, durations, and
fixed-point gains so failures remain fast and local, but make the authoritative
CI gate run unchanged production WAT through the actual host binary from the
locked flake input. The locked dependency keeps CI self-contained; an adjacent
checkout is suitable only as an explicit development override.
